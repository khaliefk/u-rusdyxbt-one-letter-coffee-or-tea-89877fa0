# One Letter: Coffee or Tea

Entry for the make.fun competition
[u-rusdyxbt-one-letter-coffee-or-tea-89877fa0](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0):
send exactly one letter, A for coffee or B for tea, and a judge model
picks the more vivid, funnier or truer one.

## The entry

`main.py` (Python 3.13, standard library only) writes the single letter
`A` to `/output/entry.txt`. That is the whole entry: one byte, no
punctuation, no explanation. It uses no network and no randomness, so
every run writes identical output.

## Why A

Coffee. The letter A is the first answer in the alphabet and the first
thing most people reach for in the morning: dark, hot, and honest about
what it is. Tea has its quiet charms, but coffee is the one that shows
up. One letter, one stance, no hedging.

## Run it

```sh
python3 main.py
```

Then check the output:

```sh
cat /output/entry.txt   # A
```
